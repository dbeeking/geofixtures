# GeoFixtures v0.1.0 — Initial public release

The first public release of GeoFixtures includes the complete deterministic geospatial fixture catalog, independent assertion and adapter architecture, strict CI behavior, raster comparison corrections, process-isolated timeouts, and the LandFuse integration test job. The pre-public corrections have been consolidated in the [changelog](../../CHANGELOG.md).

This is a pre-release project. The package is not yet published to PyPI, and its fixture answers remain pending independent review. GitHub CI should be verified after the first push.
